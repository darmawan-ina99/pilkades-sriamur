# 🗳️ Pilkades Desa Sriamur 2024 — Pusat Tabulasi Suara

Aplikasi web untuk rekapitulasi suara Pemilihan Kepala Desa Sriamur.

## Fitur
- Input suara per TPS (40 TPS, 4 calon)
- Rekapitulasi otomatis
- Grafik live real-time
- Hasil akhir dengan perhitungan otomatis
- Tabel rekap detail per TPS
- Cetak/PDF hasil
